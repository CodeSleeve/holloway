# Holloway

Welcome to the Holloway development environment.

This file contains your operating system for software development in this project.

## Commands

- **Run tests** - `vendor/bin/phpunit`
- **Run static analysis** - `vendor/bin/phpstan analyse`

## Development Rules

### Making Commits

By default, you are not authorized to make commits. Instead, prepare the commit message and any staging commands for the developer to review and commit themselves.

**Exception:** if the developer gives explicit, in-session authorization to make specific commits (e.g., after reviewing generated commit groupings/messages and asking you to run them), you may do so. When authorized, make each commit exactly as presented — same groupings, same messages — and do not alter the working directory beyond what was approved. This authorization is per-session and per-request — it does not carry forward to future sessions or to changes that haven't been reviewed.
